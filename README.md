# DailyRandom 每日随机数

每天凌晨自动更新一个 1-100 的随机数，解锁手机时显示在桌面小组件。

## 签名密钥信息

```
文件: keystore/dailyrandom.keystore
密码: dailyrandom123
别名: dailyrandom
密钥密码: dailyrandom123
有效期: 10000 天
```

## 功能

- 桌面小组件显示随机数
- 自动判断单双数
- 每天凌晨 00:00 (北京时间) GitHub Actions 自动生成新随机数
- App 内支持检查更新并下载安装
- 后台保活 + 开机自启
